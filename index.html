⚡ Kết nối Supabase Cloud (Đồng bộ Realtime Online) Chưa kết nối

Lưu trữ kết quả test tập trung trên đám mây PostgreSQL và tự động đồng bộ thời gian thực giữa nhiều thiết bị/nhân viên test

Lấy tại: Supabase Dashboard > Settings > API > Project URL
Lấy tại: Supabase Dashboard > Settings > API > Project API Keys (anon public)
📌 Hướng dẫn 3 bước kết nối Supabase Cloud:
  1. Tạo dự án mới miễn phí tại supabase.com.
  2. Vào mục SQL Editor, mở file supabase_schema.sql (đã tạo sẵn trong dự án) -> Copy & Paste vào rồi bấm Run để tạo bảng & bật Realtime.
  3. Vào Project Settings > API, copy Project URL và anon key dán vào ô bên trên rồi bấm Lưu & Kết nối.
